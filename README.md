# Drag'n Wash 🐉🧼

The first build of my game! Here's how to play it — it takes about 3 steps and no GitHub account.

---

## ▶ How to play (Windows PCs only)

### Step 1 — Download the game
Click this big link:

### 👉 **[DOWNLOAD DRAG'N WASH](https://github.com/RileyTheRex/Fluffy-Dragon-Wash/releases/latest/download/Fluffy-Dragon-Wash.zip)** 👈

It's about 1.3 GB, so give it a minute. It saves to your **Downloads** folder as `Fluffy-Dragon-Wash.zip`.

*(You can also scroll to the **Releases** box on the right of this page and click the file there — same thing.)*

### Step 2 — Unzip it
Find `Fluffy-Dragon-Wash.zip` in your Downloads, **right-click it → "Extract All…" → Extract**.
This makes a folder called **fluffy drag'n wash**. Open that folder.

> ⚠️ You have to unzip it first. Don't try to play from *inside* the zip — it won't work.

### Step 3 — Play!
Double-click **`START HERE.bat`**.

- The **first time only**, it installs the stuff Windows needs to run the game. If a blue box or a permission popup appears, click **Yes** / **Run anyway** and wait a minute.
- After that, the game opens. Every future time you play, just double-click `START HERE.bat` again and it goes straight in. 🎮

---

## ❓ If Windows tries to block it

Because I'm not a big signed company yet, Windows might show a blue **"Windows protected your PC"** box the first time.
This is normal for indie games. To get past it:

1. Click **"More info"**
2. Click **"Run anyway"**

That's it — you only have to do that once.

---

## Having trouble?
- Make sure you **unzipped** the folder (Step 2).
- Make sure you kept the whole folder together — `START HERE.bat`, the `Drag'n Wash` folder, and the `_Redist` folder all need to stay in the same place.
- Still stuck? Message me and I'll help. 🙂
